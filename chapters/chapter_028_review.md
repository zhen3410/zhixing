## 三、按严重度分级问题汇总

### 🔴 P0 — 必须修改（强AI味信号）

#### P0-1: 破折号泛滥（37处 / 121行 = 30.6%密度）
这是本章最严重的AI指纹。几乎每个段落都使用「陈述——展开/解释」的AI标志性句式：

```
阳光从另一半照进来，把他的影子切成两半。（正常）
→ 阳光从另一半照进来——把他的影子切成两半。（AI味）

茶已经凉了，杯沿上留了一圈口红印。（正常）
→ 茶已经凉了——杯沿上留了一圈口红印。（AI味）
```

**影响行**: L5(×3), L17(×3), L19, L23(×3), L31, L35, L39, L43, L47(×2), L51(×2), L53, L65(×2), L69, L75(×4), L77(×2), L79, L85(×4), L91, L95(×2), L101, L109(×2), L115, L119

**建议**: 至少削减60%。将「——」替换为句号切分、逗号衔接、或直接删除后半段解释性内容。

#### P0-2: 短句连缀（58%的行≤19字）
69行短于20字符，形成「X。Y。Z。W。」的AI标志性碎句节奏：

典型段落（L59-63）:
```
林震东接过信封。里面只有一张纸。纸上只有一行字。钢笔写的。落笔很重。横是横，竖是竖。
「归处已定。」
落款：林辰。
```

→ 这种「一句一换行」是AI最典型的节奏指纹，人类作者通常会把部分短句合并。

**建议**: 合并相关短句为节奏变化的复合句。保持部分短句用于节奏，但控制占比在30%以下。

#### P0-3: 「人名+动作」机械循环（12次林震东主导句）
如指纹#2所示，林震东的每一次出场几乎都是「林震东 + 把 + 宾语 + 动词」，形成强烈的AI生成节奏。

**建议**: 
- 用代词、环境主语、被动结构交替
- 部分动作改为对话驱动，减少叙述性动作句
- 至少削减4-5处为其他句式

#### P1-2: 「一模一样」词汇重复

三处集中出现在信纸/信封相关段落，形成重复累赘。

**建议**: 保留1处，其余替换为「如出一辙」「同款」「完全一致」等。

#### P1-3: 列表式信息铺排
- L5-11: 「三样东西」逐项罗列（照片、名单、对账单）
- L17: 「三份文件夹」按颜色标签分类（红/蓝/黄）

AI标志性的「先总后分、逐条展开」信息组织方式。

**建议**: 至少将一处改为非线性呈现，穿插在对话中自然流露。

这是AI角色塑造的经典模板：身体伤痕 = 深层人设，用一次性细节完成人物深度。

同一章内两次用影子作为权力/关系的视觉隐喻，重复度高。
